# 🕊️ بروشور كنيسة القديسين بايسيوس وصوفرونيوس وبورفيريوس الإلكتروني التفاعلي
### للروم الأرثوذكس / طريق المطار
> «معًا نبني بيتًا يُرفع فيه القلب إلى الله»

---

## 📖 نبذة عن المشروع
تم تصميم وتطوير هذا البروشور الإلكتروني التفاعلي ليكون تجربة رقمية تجمع بين **الهوية الأرثوذكسية الشرقية العريقة** و**التصميم العصري الأنيق للمجلات والبروشورات الرقمية الحديثة**.

يعتمد التصميم على لوحة ألوان دافئة وروحانية (الألوان الكريمية، العاجية، الذهبية، والماروني العنابي المستوحى من شعار الكنيسة الرسمي)، مع حركات انتقال انسيابية، ونصوص مقتضبة ومؤثرة، ودعم كامل للغة العربية (RTL).

---

## 🏛️ أقسام البروشور الستة
1. **الغلاف المبارك:** اسم الكنيسة الرسمي، الشعار، والعبارة المركزية: «معًا نبني بيتًا يُرفع فيه القلب إلى الله».
2. **الرؤية والرسالة:** توضيح أن الكنيسة بيت للصلاة، والشركة، والمحبة، ومنارة للإيمان للأجيال القادمة، مع الآية الروحية (تكوين 28: 17).
3. **القديسون الشفعاء:** استعراض أيقونة القديسين الثلاثة (بايسيوس الآثوسي، صوفرونيوس بطريرك أورشليم، وبورفيريوس الكافسوكاليفي) مع بطاقة تفاعلية لنبذة روحية، تذكارهم الليتورجي، وأقوالهم المأثورة.
4. **صرح الكنيسة والمشروع:** استعراض التصميم المعماري البيزنطي ثلاثي الأبعاد مع **نقاط تفاعلية (Hotspots)** لاستكشاف القبة المركزية، برجي الأجراس، الصحن البازيليكي، والساحة والمجمع الرعائي، بالإضافة لجدول مراحل التنفيذ.
5. **ساهم في البناء («تبرع بحجر»):** محاكي بصري تفاعلي يتيح للزائر اختيار عدد الحجارة (1، 5، 20، 50، أو قيمة مخصصة) ورؤية أثر مساهمته الفوري على الجدار الروحي التفاعلي، مع عرض الحسابات البنكية ومعرّف كليك (CliQ).
6. **الخاتمة والدعوة:** عبارة «فلنبنِ معًا بيتًا لله»، وأزرار سريعة ومباشرة لزيارة الموقع الرسمي، والتبرع، والمشاركة عبر **واتساب** و**فيسبوك**، ونسخ الرابط، وطباعة البروشور.

## ✨ المميزات التفاعلية المدمجة
* **نمطان للعرض والتصفح:**
  * **نمط الكتيّب التفاعلي (Interactive Magazine Mode):** عرض شرائح متتابع يحاكي تقليب صفحات المجلة، مع مؤشر الصفحات، دعم مفاتيح الأسهم، وإيماءات السحب باللمس على الهواتف الذكية.
  * **نمط القراءة الانسيابية (Continuous Scroll Mode):** تصفح انسيابي متصل لجميع الأقسام بنقرة واحدة.
* **نغمات كنسية روحانية هادئة:** مولّد نغمات جرس خفيف مدمج عبر تقنية Web Audio API دون الحاجة لملفات صوت خارجية قد تبطئ التحميل.
* **مشاركة ذكية عبر واتساب وفيسبوك:** بنقرة واحدة تُرسل رسالة منسقة وجاهزة مع الرابط وشعار الكنيسة.
* **نسخ فوري للآيبان ومعرّف كليك (CliQ):** مع إشعارات توست عائمة وأنيقة.
* **جاهز للطباعة وتصدير PDF:** يدعم الطباعة النظيفة بنسق مطبوع أنيق عبر زر `طباعة / حفظ PDF`.

كافة النصوص، الروابط، وأرقام الحسابات يمكن تعديلها في ثوانٍ من خلال ملف واحد مخصص:
👉 **`assets/js/brochure-config.js`**

```javascript

  // الروابط الرسمية (استبدلها بروابطك عند إطلاقها)
  links: {
    officialWebsite: "https://your-church-domain.org",
    donationPage: "https://your-church-domain.org/donate",
    facebookPage: "https://facebook.com/...",
  },
  
  // الحسابات البنكية
  donateAStone: {
    currency: "دينار",
    stoneCost: 50, // القيمة الرمزية للحجر
    bankAccounts: [
      {
        bankName: "البنك المعتمد",
        accountName: "مشروع بناء كنيسة القديسين بايسيوس وصوفرونيوس وبورفيريوس",
        iban: "JO00...",
        cliqAlias: "CHURCH-STONES"
      }
    ]
  }
};
```

## 🚀 طريقة التشغيل والنشر
1. **التشغيل المباشر:** ما عليك سوى النقر المزدوج على ملف `index.html` في أي متصفح حديث (Chrome، Safari، Edge، Firefox).
2. **الرفع على الإنترنت:** الملفات ثابتة (Static Web Files) بالكامل، ويمكن رفعها مباشرة إلى:
   - استضافة موقع الكنيسة الحالي.
   - GitHub Pages (مجانًا).
   - Vercel أو Netlify أو أي مزود استضافة ويب.
